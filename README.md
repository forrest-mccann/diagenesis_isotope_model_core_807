## Getting Started

### Option 1: Clone with Git (recommended)

```
git clone https://github.com/forrest-mccann/diagenesis_isotope_model_core_807.git
cd diagenesis_isotope_model_core_807
```

### Option 2: Download as a ZIP

1. Go to the [repository page](https://github.com/forrest-mccann/diagenesis_isotope_model_core_807).
2. Click the green **Code** button, then **Download ZIP**.
3. Unzip the file and open the resulting folder.

### Next steps
